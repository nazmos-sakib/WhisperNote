Selected-text actions

Added native selectable transcript and translation text with Share… and Translate with… actions.
Share uses ACTION_SEND/text/plain; Translate with uses ACTION_PROCESS_TEXT/text/plain and read-only=true.
Only the highlighted substring is passed. No translation result is written back to the note.
PROCESS_TEXT package visibility is declared; no matching handler produces a message suggesting Share.
Android's process-text chooser may include other text tools as well as translation apps.
